# Using Animate.css for Animations

Animate.css is now installed and globally available in your project. You can add beautiful, modern animations to any element by applying Animate.css classes.

## How to Use

1. **Add Classes to Elements:**
   - `animate__animated` (required)
   - Animation type, e.g., `animate__fadeIn`, `animate__bounce`, `animate__slideInUp`, etc.
   - Optional: `animate__delay-1s`, `animate__faster`, etc.

**Example:**
```jsx
<div className="animate__animated animate__fadeInUp animate__delay-1s">
  Animated content here
</div>
```

2. **Where to Use:**
   - Buttons, cards, modals, page sections, notifications, etc.
   - For page transitions, wrap main containers or sections.

3. **Animation List:**
   - See all available animations: https://animate.style/

## Best Practices
- Use subtle animations for a modern, professional feel.
- Avoid overusing animations on every element.
- Combine with CSS transitions for hover/focus effects.
